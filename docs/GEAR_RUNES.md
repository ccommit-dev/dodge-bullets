# 세트 파츠 룬 홈

2026-11-17 사용자 요청 "아이템 부여나 강화 시에 보석을 넣는다거나 조금 더 재미 요소를"으로 넣었다. 세트 파츠(투구 · 갑옷 · 장갑 · 신발 · 견갑)를 강화하면 룬 홈이 열리고, 후보 세 장 중 하나를 골라 새긴다.

## 규칙

| 항목 | 내용 | 코드 |
|---|---|---|
| 홈 | 강화 +3 · +6 · +9 에서 하나씩, 파츠마다 최대 3칸. 한정 파츠(오텀 장갑)는 홈이 없다 | `equipment/gearRunes.ts` `runeSocketCount` |
| 열기 | 빈 홈이나 새긴 홈을 누르면 강화석 3 · 은화 20 을 내고 후보 세 장을 본다 | `RUNE_OPEN_COST` |
| 다시 뽑기 | 강화석 2 | `RUNE_REROLL_COST` |
| 후보 | 서로 다른 룬 셋. 등급 일반 70 · 희귀 25 · 영웅 5%, 효과 ×1 · ×1.5 · ×2. 후보는 저장에 남고, 뽑을 때마다 `runeRolls` 가 늘어 같은 후보가 다시 나오지 않는다 | `rollRuneOffer` |
| 공명 | 한 파츠의 홈 셋이 같은 룬이면 그 파츠 룬 효과 ×1.5, 입은 파츠가 룬 색으로 빛난다 | `runeResonance` · `ui/gearRunes.css` |
| 효과 | 낀 파츠의 열린 홈만 센다 | `gearRuneEffects` |

## 룬 네 가지와 상한

힘은 사냥 속도 고정(30일차 24~25층) 안에 둔다. 그래서 룬은 세기보다 쓰임새를 바꾸고, 룬마다 합계 상한이 있다. 한 룬의 공명 파츠 하나로 상한에 거의 닿는다. 여러 룬을 섞어 쓰게 하려는 의도다.

| 룬 | 효과 | 한 칸(일반) | 상한 |
|---|---|---|---|
| 불꽃 룬 | 탭 치명 확률 | +1%p | +6%p |
| 바람 룬 | 동료 공격 속도 | +0.8% | +5% |
| 대지 룬 | 대장 제한시간 | +0.3초 | +2초 |
| 황금 룬 | 사냥 골드(처치 · 긴급 의뢰) | +1.5% | +10% |

새 재화는 없다. 룬은 가방에 쌓이는 아이템이 아니라 홈에 새기는 효과다. '보석'은 유료 재화 이름이라 쓰지 않는다.

## 바꿀 때

- 값은 `RUNE_DEF`(한 칸 값 · 상한) 한 곳에서 바꾼다.
- 상한을 올리면 `verify-pace-lock` 을 먼저 돌린다. 시뮬은 세트 파츠를 세지 않으므로, 상한을 크게 올리면 실제 진행이 시뮬보다 빨라진다.
- 검사: `verify-gear-runes`(로직 26) · `verify-gear-runes-ui`(장비창 화면 17).
