DODGE LAB 개인정보처리방침

시행일: 2026-08-22 · 앱: DODGE LAB (com.ccommit.dodgelab)

1. 개요

DODGE LAB(이하 "본 앱")은 오프라인 싱글 플레이 게임입니다. 본 앱은 개인정보를 수집·전송·판매하지 않습니다.

2. 수집하는 정보

  • 수집하지 않습니다. 이름, 이메일, 전화번호, 위치, 광고 식별자, 기기 식별자를 포함한 어떤 개인정보도 수집하지 않습니다.
  • 회원가입·로그인 기능이 없습니다.

3. 기기 내 저장 데이터

  • 게임 진행 상황(스테이지, 재화, 설정 등)은 사용자 기기 내부에만 저장됩니다.
  • 이 데이터는 외부 서버로 전송되지 않으며, 앱 삭제 시 함께 삭제됩니다.

4. 제3자 제공 및 광고

  • 제3자에게 제공하는 정보가 없습니다.
  • 광고 SDK 및 분석(애널리틱스) SDK를 포함하지 않습니다.

5. 아동의 개인정보

본 앱은 어떤 이용자의 개인정보도 수집하지 않으므로, 아동의 개인정보 역시 수집하지 않습니다.

6. 방침 변경

기능 추가(예: 광고, 클라우드 저장)로 처리 방침이 달라질 경우 본 페이지를 통해 사전 고지하고, 변경된 시행일을 명시합니다.

7. 문의

개인정보 관련 문의: GitHub 저장소 이슈 트래커 (github.com/ccommit-dev/dodge-bullets/issues)

DODGE LAB Privacy Policy

Effective: 2026-08-22 · App: DODGE LAB (com.ccommit.dodgelab)

Summary

  • DODGE LAB is an offline single-player game. It does not collect, transmit, or sell any personal data.
  • No sign-up or login. No ads or analytics SDKs. No third-party data sharing.
  • Game progress is stored only on your device and is deleted when you uninstall the app.
  • Questions: GitHub issue tracker.
