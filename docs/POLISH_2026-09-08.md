## 2. 동료 애니메이션 (`titans/SpriteArt.tsx` · `App.css`)

- **공격 3박**: 예비(이동 프레임 90ms, 뒤로 당김) → 타격(공격 프레임 240ms, 앞으로 찌르기 + 살짝 커짐 + 밝기) → 복귀(대기 프레임 150ms, settle). 예전엔 공격 프레임 320ms 고정이라 "포즈 변경"이지 "타격"이 아니었다.
- **걷기 2프레임 사이클**: 접근 중 이동 프레임 하나를 흔들기만 하던 것을 140ms 마다 이동↔대기 프레임 교대. 몸의 흔들림은 위아래 발구름만.
- **대기**: bob 1.7s + breathe 1.9s 두 겹이 맞물려 떨리던 것을 3.2s 한 겹 + 미세 호흡으로.
- 상태 결정은 순수 함수 `allyFrameFor`(피격 > 공격 > 걷기) — `verify-systems.mjs` 가 단언.

## 3. 화살 원정 — 베기 쪼개짐 (`game/arrows.ts` · `draw.ts`)

베면 화살이 그냥 사라졌다. 이제 `spawnCutDebris` 가:
- **파쇄**: 검격 지점에서 **촉 토막·깃 토막** 두 조각이 검이 지나간 방향으로 갈라져 날아가고(중력·바닥 튕김·회전), 잘린 단면에 흰 점, 검광(흰 선) + 불꽃 5.
- **반사**: 화살은 살아서 되돌아가므로 금색 불꽃 7 + 검광만.
- **보스 베기**: 붉은 불꽃 + 검광. **일섬**: 화면 화살 전부 파쇄 연출.
파편은 `slashDebris` 풀(48) — 충돌 없음, 1.3초 안에 소멸. `verify-content.mjs` 단언.

## 16. 기기 스크린샷 4건 (2026-09-18)

- **오우거가 허벅지에서 잘림** — 컨테이너 문제가 아니라 원화 자체가 잘려 있었다 (`ogre.png` 하단 여백 0.0%, 무릎 아래가 없음. 고블린·이끼 골렘도 같은 증상). `art-gen/gen.py` 에 `monster` 명령을 추가해(기존 몬스터 원화를 IP 참조로 화풍 고정, "full body … feet planted" 프롬프트·"cropped, cut off legs" 네거티브) 4시드를 뽑고, `scripts/place-monster.mjs` 로 가로 중앙·발 여백 1% 에 앉혔다. 512×512, 좌우 여백 5.1%. hit/defeat 프레임 재생성.
- **오우거 오른쪽 동료가 몬스터보다 오른쪽에 섬** — 근접 앵커가 필드 좌표로 계산되는데 동료 칸의 `left` 는 `.titans-allies` 기준이고 이 컨테이너는 모바일에서 필드보다 11%(40px) 오른쪽에서 시작한다. 그만큼 빼지 않아 오른쪽 동료가 몬스터 몸에서 23px 떨어져 허공을 쳤다. `--allies-left` 를 도입해 좌표를 맞추고, 좌우 반전(`face-left`) 슬롯은 그림 위치가 뒤집히는 것(28.5~88% → 12~71.5%)까지 반영했다. 실측 간격 23px → 접촉, play-art 겹침 33%(상한 40%).
- **STAGE CLEAR 가 왼쪽으로 치우침** — 절대 배치 요소에 폭이 없어 shrink-to-fit(필드폭−left=182px)으로 줄어 "STAGE / CLEAR" 로 접히고, 글자는 그 안에서 왼쪽 정렬됐다. `width:max-content; max-width:92%; text-align:center` 로 한 줄·중앙 정렬 (실측 206px, 1줄, 중심 오차 0).
- **마이페이지 캐릭터가 왼쪽으로 치우침** — 원화의 머리·상반신이 칸 중심보다 17.9% 오른쪽에 있다(망토·무기가 왼쪽을 채워 전체 bbox 중심은 정중앙). 프리뷰는 상반신만 보여 주므로 그만큼 왼쪽으로 밀어 얼굴을 프레임 가운데에 맞췄다.

## 17. UI·아이콘 정리 (2026-09-18)

"UI나 아이콘이 너무 복잡하다 — 불필요하거나 중복된 것 정리, 애매하면 합쳐라". 화면마다 보이는 아이콘·버튼·텍스트 조각을 세고 같은 문구가 몇 번 나오는지 뽑는 임시 감사 스크립트로 먼저 재 봤다(허브 21아이콘·19버튼·52조각, 모험 팝업 28버튼·76조각).

### 같은 곳으로 가는 두 번째 입구

| 중복 | 조치 |
|---|---|
| 모험 팝업에 "토벌" 과 "일일 퀘스트" 버튼이 나란히 — 목적지(`events/daily`)도 설명도 같았다 | 진행 상태(미수령/모두 수령)가 보이는 루틴 타일만 남기고 이름을 "일일 퀘스트" 로 합침 |
| 모험 팝업의 "이벤트 상점" — 하단 '상점' 탭 안에 이미 '이벤트' 탭이 있다 | 제거 (팝업 7칸 → 5칸) |
| 관리 시트 큰 제목이 바로 옆 전환 탭과 같은 말("동료 도감", "상점") | 제목 블록 제거 — 전환 탭이 제목 역할을 한다 |

### 같은 값을 두 번 읽게 하던 라벨

| 중복 | 조치 |
|---|---|
| 방치 카드 머리말 "시간당 · 최대 12h" + 바로 아래 요약 "최대 12h 누적 시…" | 머리말은 "시간당" 만 |
| 방치 카드 머리말 "자동 사냥 중 · STAGE 14" + 바로 위 제목 "STAGE 14 · 1/10" | 머리말에서 STAGE 제거 |
| 칩마다 붙던 "/h" 3회 (머리말이 이미 "시간당") | 단위 대신 무엇인지를 — 골드 / EXP / 강화석 |
| 동료 도감 설명 "근딜·원딜·탱커·힐러와 불·물·흙·바람 조합으로" + 바로 위 역할 필터 칩 | "역할과 속성을 섞어 편성하세요." |
| 마이페이지 도감 칩마다 "10마리부터 · 다음 10" (머리말이 이미 "처치 마일스톤 → 골드 보너스") | 진행도 한 줄 `250 / 1,000`, 보너스는 받은 뒤에만 |
| 캐릭터 칩 "패시브 없음 · 미보유" | 없는 것을 굳이 말하지 않는다 — 미보유만 |
| 전장 알림이 최대 5줄까지 쌓여 전장을 덮음 | 목표 알림 1줄 + CSS 로 스택 2줄 상한 |

### 아이콘

하단 내비 5칸 중 둘(사냥터·콘텐츠)만 그림 아이콘이고 셋은 글자 기호(`✓` 모험 · `♟` 동료 · `▰` 상점)였다. `✓` 는 뜻도 맞지 않았다(모험 = 균열·일일 퀘스트·강화·파견·시즌 패스).

- 모험 → 기존 8칸 스프라이트의 포털(`event`) 칸.
- 동료·상점 → 스프라이트에 없어 새로 뽑았다(`art-gen/batch-nav-icons.sh`, 출석 보상 아이콘을 IP 화풍 앵커로). 투구 셋 · 시장 좌판. 알파 여백을 잘라 128px 낱장으로 붙인다.
- 모험 팝업 안에서도 시즌 패스만 `★` 글자였다 — `ui/idle/star.svg` 로 통일.
- 쓰이지 않게 된 `.nav-symbol` 규칙 제거.

### 글자 접힘

썸네일이 왼쪽 칸을 차지해 도감 칩의 글자 폭이 46px 뿐이었다 — "슬라임" 이 "슬라/임" 으로, "250 / 1,000" 이 두 줄로 접혔다. 썸네일을 줄이고(46→38, 캐릭터 40→34) 낱말 중간 줄바꿈을 막고(`word-break: keep-all`) 도감을 3열 → 2열로.

**결과**: 같은 저장 상태로 재 보면 허브 19버튼 → 18버튼, 모험 팝업 28버튼 → 24버튼(7칸 → 5칸), 중복 문구는 허브·상점·동료 화면에서 모두 사라졌다(남은 것은 하단 내비 라벨과 시트 탭이 같은 이름인 경우뿐 — 현재 위치 표시라 의도한 중복이다). 내비 5칸 전부 같은 계열의 그림 아이콘.
