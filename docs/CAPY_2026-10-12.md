# 납작한 벡터 카툰 재디자인 — "카피바라 키우기" 느낌 (2026-10-12)

사용자 지시: 참고 캡처(카피바라 키우기)처럼 디자인 다시 · 애니메이션 방향 오른쪽 · 땅을 걷는 듯한 맵 · 배경 맵 어색함 수정.

## 참고에서 읽은 규칙
- **화풍**: 굵은 짙은 외곽선 · 셀 셰이딩(그림자 1단) · 단순 도형 · 파스텔 원색. 몸통이 크고 팔다리가 짧은 치비. 3D 광택·그라데이션·털 질감 없음.
- **맵**: 옆에서 본 2D 횡스크롤. 위 1/3 은 하늘과 집·나무가 **지면선 위에 서 있는** 배경 띠, 아래 2/3 는 넓고 평평한 흙 땅(캐릭터가 걷는 곳) + 얇은 잔디 띠. 원근 다리·조감·물 위 걷기 없음.
- **방향**: 주인공·동료는 오른쪽(몬스터 쪽), 몬스터는 왼쪽.

## 생성 파이프라인
- `ARTGEN_LOOK=flat` (art-gen/gen.py): 3D 토이 문구를 빼고 `flat vector cartoon, thick dark outlines, cel shading, sticker style, chibi` 를 **프롬프트 맨 앞**에 붙인다(CLIP 77 토큰 잘림 대비). 배경 스타일은 "옆에서 본 지면선 · 위 1/3 배경 띠 · 아래 2/3 평평한 땅" 으로 교체, 네거티브에 isometric·bird's eye·perspective road.
- 참조: `art-gen/ref/capy/` (캡처에서 오린 카피바라 2장), IP 0.25 — 0.35 는 비버가 카피바라가 됐다(1차 프로브).
- 1차 프로브 `batch-capy1.sh`(주인공·미아·가시덤불·초원) → 2차 전부 `batch-capy2.sh`(주인공 3시드 · 동료 11 ×2 · 몬스터 31 ×2 · 배경 13 ×2).
- 컷아웃: 납작 화풍은 바닥 그림자가 남아 NX 위치 매트가 "배경이 단색이 아님" 으로 거부 → rembg 폴백이 깨끗하게 오려낸다(프로브 확인).

## 반영 (코드)
- 사냥터 `.titans-background` 를 위 기준으로 맞추고 주인공·동료·몬스터의 bottom 을 땅 띠 안으로 올린다(아래 2/3 흙 위에 서게).
- 성문 방어 `drawStageBackground`: 배경을 바닥선에 맞춰 깔고, 바닥 아래 어두운 띠를 흙색 납작 띠로.
- 성문 방어 주인공 시트 교체 시 `EXPEDITION_NATIVE_FACING` 을 +1(오른쪽 보기)로.
- 비트 무대 `public/beat/bg/stage.webp` 교체.

## 남은 것 · 어색한 점
1. 성문 방어의 띠 위 하늘은 그림 꼭대기 색 한 가지로 채워 밋밋하다 — 구름 몇 개를 코드로 그리거나 세로 긴 띠(1216×1024)로 재생성.
2. 사냥터 상단 띠가 스테이지 줄·사냥 강화 바에 가려 1/3 만 보인다 — 띠 높이 44% 를 유지하되 사냥 강화 바를 접이식으로.
3. 몬스터 피격·처치 프레임은 기울임·눌림 파생이라 납작 원화에서는 "스티커가 흔들리는" 느낌 — 피격은 밝기 번쩍임만으로 줄이는 안.
4. 늑대왕(wolf-king)·달빛 늑대왕은 늑대로 읽히게 capy3 에서 다시 뽑았다 — 다른 대장(보스) 중 식별이 약한 것(ruin-sentinel·void-lich) 도 한 번 더 뽑을 여지.
5. UI 아이콘·프레임(나무 아케이드)은 그대로 — 납작 카툰 캐릭터와 섞여도 어색하진 않지만, 참고(카피바라)처럼 단색 둥근 버튼으로 가면 더 통일된다.
6. 뒷모습 주인공(성문 방어에서 위를 보는 포즈)은 여전히 없다 — 옆모습 반전 + 기울기.
