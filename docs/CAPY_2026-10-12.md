# 납작한 벡터 카툰 재디자인 — "카피바라 키우기" 느낌 (2026-10-12)

사용자 지시: 참고 캡처(카피바라 키우기)처럼 디자인 다시 · 애니메이션 방향 오른쪽 · 땅을 걷는 듯한 맵 · 배경 맵 어색함 수정.

## 참고에서 읽은 규칙
- **화풍**: 굵은 짙은 외곽선 · 셀 셰이딩(그림자 1단) · 단순 도형 · 파스텔 원색. 몸통이 크고 팔다리가 짧은 치비. 3D 광택·그라데이션·털 질감 없음.
- **맵**: 옆에서 본 2D 횡스크롤. 위 1/3 은 하늘과 집·나무가 **지면선 위에 서 있는** 배경 띠, 아래 2/3 는 넓고 평평한 흙 땅(캐릭터가 걷는 곳) + 얇은 잔디 띠. 원근 다리·조감·물 위 걷기 없음.
- **방향**: 주인공·동료는 오른쪽(몬스터 쪽), 몬스터는 왼쪽.

## 생성 파이프라인
- `ARTGEN_LOOK=flat` (art-gen/gen.py): 3D 토이 문구를 빼고 `flat vector cartoon, thick dark outlines, cel shading, sticker style, chibi` 를 **프롬프트 맨 앞**에 붙인다(CLIP 77 토큰 잘림 대비). 배경 스타일은 "옆에서 본 지면선 · 위 1/3 배경 띠 · 아래 2/3 평평한 땅" 으로 교체, 네거티브에 isometric·bird's eye·perspective road.
- 참조: `art-gen/ref/capy/` (캡처에서 오린 카피바라 2장), IP 0.25 — 0.35 는 비버가 카피바라가 됐다(1차 프로브).
- 1차 프로브 `batch-capy1.sh`(주인공·미아·가시덤불·초원) → 2차 전부 `batch-capy2.sh`(주인공 3시드 · 동료 11 ×2 · 몬스터 31 ×2 · 배경 13 ×2).
- 컷아웃: 납작 화풍은 바닥 그림자가 남아 NX 위치 매트가 "배경이 단색이 아님" 으로 거부 → rembg 폴백이 깨끗하게 오려낸다(프로브 확인).

## 반영 (코드)
- 사냥터 `.titans-background` 를 위 기준으로 맞추고 주인공·동료·몬스터의 bottom 을 땅 띠 안으로 올린다(아래 2/3 흙 위에 서게).
- 성문 방어 `drawStageBackground`: 배경을 바닥선에 맞춰 깔고, 바닥 아래 어두운 띠를 흙색 납작 띠로.
- 성문 방어 주인공 시트 교체 시 `EXPEDITION_NATIVE_FACING` 을 +1(오른쪽 보기)로.
- 비트 무대 `public/beat/bg/stage.webp` 교체.

## 결과 (2026-10-12 오후)
- batch-capy2 전부 렌더(주인공 3 · 동료 22 · 몬스터 62 · 배경 26, 약 2.5시간) + batch-capy3(미노타우로스·늑대왕 재생성).
- **배치**: 주인공 heroidle-capy2-20272001(반전) · 동료 11(시드 선택, nox 반전) · 몬스터 31(`art-gen/capy2-seeds.txt`, 미노타우로스는 capy3) · 배경 13(초원 02·숲 04·폐허 06·협곡 08·심연 09 · 성문 12/14/16/18/20 · 허브 22 · 대장간 23 · 비트 25).
- **QA**: 동료 11·몬스터 31 전부 sprite-qa ≥ 60 (처음 미노타우로스 57 → capy3 로 100).
- **얼굴 방향**: SDXL 은 "facing right" 를 자주 무시한다(주인공 3시드 중 1만 오른쪽). 생성 뒤 접촉 시트(scripts/_contact.mjs)로 보고 `--flip=` 로 뒤집는 쪽이 빠르다 — 반전한 것: 주인공·녹스.
- **배경 레이아웃**: 세로 832×1216 은 만화 칸·집 한 채가 꽉 찬 그림이 나와, 가로 1216×832 지평선 띠(`ARTGEN_BG_SIZE`)로 바꾸고 땅은 코드가 그린다(사냥터 `.titans-ground`, 성문 `drawStageBackground` 흙 띠, 비트 무대 바닥).

## 남은 것 · 어색한 점
1. 성문 방어의 띠 위 하늘은 그림 꼭대기 색 한 가지로 채워 밋밋하다 — 구름 몇 개를 코드로 그리거나 세로 긴 띠(1216×1024)로 재생성.
2. 사냥터 상단 띠가 스테이지 줄·사냥 강화 바에 가려 1/3 만 보인다 — 띠 높이 44% 를 유지하되 사냥 강화 바를 접이식으로.
3. 몬스터 피격·처치 프레임은 기울임·눌림 파생이라 납작 원화에서는 "스티커가 흔들리는" 느낌 — 피격은 밝기 번쩍임만으로 줄이는 안.
4. 늑대왕(wolf-king)·달빛 늑대왕은 늑대로 읽히게 capy3 에서 다시 뽑았다 — 다른 대장(보스) 중 식별이 약한 것(ruin-sentinel·void-lich) 도 한 번 더 뽑을 여지.
5. UI 아이콘·프레임(나무 아케이드)은 그대로 — 납작 카툰 캐릭터와 섞여도 어색하진 않지만, 참고(카피바라)처럼 단색 둥근 버튼으로 가면 더 통일된다.
6. 뒷모습 주인공(성문 방어에서 위를 보는 포즈)은 여전히 없다 — 옆모습 반전 + 기울기.

## 2차 (2026-10-12 오후, 사용자: 적은 왼쪽·아군은 오른쪽을 정확히 · UI 여백/금액 잘림 · 보완 목록 1~8 · 파츠 6종·콘텐츠 4종 · 투구/무기/갑옷 애니메이션 반영)
- **방향 검사 자동화**: `scripts/facing-scan.mjs`(NX 어두운 덩어리 무게중심)가 납작 원화에서는 잘 맞는다(눈으로 확인한 13장과 일치). 아군 11 중 왼쪽을 보던 세라·가렌·녹스는 `--flip=` 으로 반전, 몬스터 31 중 오른쪽을 보던 아머드 오우거·헬하운드·고목 수호자·고블린 군주는 FLIP_MONSTERS. 정면(front)은 그대로.
- **5차 배치(batch-capy5)**: 방향을 더 엄격히("head turned right, both eyes looking to the right edge, nose pointing right") 쓰고 참조도 같은 방향 납작 원화로 바꿔 주인공·동료·몬스터를 다시 뽑는다. 뒷모습 주인공은 SDXL 이 참조에 끌려 정면을 그려(char-capy5-heroback) 실패 — 성문 방어는 옆모습 반전 + 조준 기울기로 유지.
- **금액 잘림**: `formatGold` 반올림 경계(999,950 → "1000.0K" 가 아니라 "1.00M") · 지갑 칩 축소(폰 420px 이하 11px) · `scripts/scan-overflow.mjs` 로 13화면 잘림/넘침 스캔(남은 것: 스킬 탭 `.titans-float` 글자가 전장 밖으로 — 애니메이션 중 일시, 보정 불필요).
- **보완 1·2·3·5**: 성문 하늘 납작 구름(`drawFlatClouds`) + 꼭대기 고정 하늘색 · 사냥 강화 바 접이식(6초 뒤 칩) · 몬스터 피격 반동 2px+번쩍임 · 납작 단색 버튼/탭/카드 테마(`--flat-*`, 크림 면·갈색 외곽선·아래 그림자).
- **보완 4**: ruin-sentinel·void-lich 를 1024 대장으로 다시 뽑는다(5차).
- **파츠 6종(투구·갑옷·무기·방패·장갑·신발) × 3티어**: 5차 아이콘 18장 → `scripts/place-gear.mjs` 가 `public/titans/gear/`(오버레이)·`public/ui/gear/`(아이콘) 로. 캐릭터 애니메이션에는 투구(견갑 강화 +1/+5/+10)·가슴 갑옷(견갑 종류)·무기(검 강화)를 `EquippedCharacter`(사냥터)와 성문 방어 캔버스(`drawGearPart`)에 앵커로 얹는다. 앵커는 납작 주인공(인물 y 31~100%) 기준으로 다시 잡았다.
- **콘텐츠 카드 4종**(성문·탑·비트·대장간): 5차 1024 카드 → `public/ui/content-cards/*.webp`, 콘텐츠 선택 카드 아래 그림.
- **임시 자산** (`scripts/make-placeholder-gear.mjs`): 5차 배치가 GPU 를 못 받아 멈춘 동안 파츠 18장은 납작 SVG(나무/철/금), 콘텐츠 카드 4장은 기존 지평선 띠 배경을 오린 것으로 채워 404 를 막았다. 배치가 끝나면 `place-gear.mjs` 가 덮어쓴다.
- **GPU 정체의 진짜 원인**: 다른 작업이 아니라 TaskStop 뒤 살아남은 우리 bash 루프 4개가 각각 생성기를 띄워 GPU 를 나눠 쓰고 있었다(287 s/it). PID 로 전부 끝내자 4.3GB·6% 로 돌아왔고 5차 배치를 한 번만 다시 돌린다.
