# 콘텐츠 집중도 기획 수정 — 카피바라 Go! 구조에서 가져올 것 (2026-10-13)

참고: 나무위키 「카피바라 Go!」(2026-08-14 판) — Habby 의 텍스트 로그라이크 육성. 아래 "카피 Go" 는 그 문서 요약이고, "우리" 는 비버 키우기 현 상태(코드 기준)다.
앞선 기획(LOOP_2026-10-08: Galactic Outlaw 7요소, CONTENT_ROLES_PLAN: 콘텐츠 역할 분리)은 **한 판 안의 밀도**를 올렸다. 이번 수정은 **판과 판 사이 — 어디로 가야 하는지, 왜 또 들어오는지**를 한 화면에 모으는 쪽이다.

## 1. 카피 Go 가 집중도를 만드는 방식 (문서에서 읽은 것)

| # | 장치 | 핵심 |
|---|---|---|
| A | **5탭 고정 · 가운데가 모험** | 상점·장비·**모험**·특성·보물상자. 실제 플레이 콘텐츠는 전부 모험 한 화면에서 진입. 로비가 허브다. |
| B | **하루 단위 진행 + 2택** | 메인 챕터는 "다음 날" 버튼 하나로 휴식·전투·2택 사건이 흐르고 가끔 스킬 선택이 끼어든다. 손은 적고 결정은 잦다. |
| C | **챕터 타입 순환 60→60→30→30→5일** | 같은 콘텐츠인데 길이와 장치(룰렛·행운 상인 머신·타워 5웨이브)가 달라 지루하지 않다. |

| E | **도전 5종이 한 버튼 아래** | 타워(100층×10단계, 도전권) · 경기장(주간 티어) · 지하감옥 돌진(연속 돌파, 층마다 2택) · 고블린 광부(미니게임) · 봉인의 전투(누적 피해 랭킹). |

| G | **특성 = 골드 → HP/공/방 + 승급 이정표** | 세 능력치 만렙 → 승급. 합계가 1/3 이면 골드, 2/3 이면 **영구 스킬**(골드 디거·융통·건장 …). 숫자 올리기에 "다음 보상이 보이는" 중간 계단. |
| H | **영웅의 전승 = 빌드 계열** | 해골(연타)·기사(반격)·유협(치명)·유령(스킬)·드래곤. 스킬 풀이 계열별로 갈라져 "내 빌드"가 생긴다. |
| I | **보물상자 포인트 루프** | 상자를 열면 포인트 → 포인트로 다시 상자. 수집품·조각·성급 돌파. |
| J | **장비 = 4부위 · 강등 100% 환급 · 도면 승급(특성 레벨 게이트)** | 실수 비용 0, 승급 조건이 다른 축(특성)과 묶여 서로를 끌어당긴다. |
| ✗ | **비판에서 피할 것** | 로비 알림 폭탄 · 스킬 설명 모호 · 명칭 비일관("카피카피킹/왕") · 2중 결제 이슈 · 합성 난이도 흉악(신화 1개에 에픽 18+126개). |

## 3. 기획 수정 (우선순위 · 어디를 고치는가 · 검사)

### P0 — 한 화면 허브 (A + E + F)
- **모험 탭을 "오늘 할 일" 허브로**: 위 1/3 사냥터 그대로, 아래 2/3 에 **카드 6장 고정**: 성문 방어 · 비트 수련 · 성벽 · 주말 균열 · 대장간 · 원정 지도. 카드마다 ① 남은 횟수/티켓 ② 오늘 보상 1줄("강화석 +12") ③ 빨간 점(할 수 있는데 안 한 것만). 콘텐츠 팝업은 카드 6장의 복제라 없앤다.
  - 코드: `src/TitansGame.tsx` 콘텐츠 팝업(`data-card`) → 허브 섹션 `.hub-cards`로, 카드 데이터는 `src/titans/hubCards.ts` 신설(id·title·feeds·remaining(save)·todayReward(save)). 기존 `public/ui/content-cards/*.webp` 재사용.
  - 검사: `scripts/verify-content.mjs` 에 "허브 카드 6장 · 각 카드 남은 횟수 문구 · 빨간 점은 할 수 있는 카드에만".
- **자원 즉답**: 카드의 `feeds` 를 재화 아이콘 1~2개로(강화석·조각·인장·보석). 상점 카드의 "→ 어디에 쓰이는가" 와 같은 문법(LOOP 2026-10-08).
- **실패 시 티켓 미소모 통일(F)**: 성벽·갈림길·주말 균열 — 보상을 받을 때만 티켓/횟수 차감. 재시도는 무제한. `towerTickets` 차감 위치를 층 보상 지급 함수로 옮긴다.
  - 검사: verify-systems "성벽 실패 → towerTickets 그대로, 클리어 → −1".

### P0 — 소탕(탐방) 배율 (D)
- **성문 방어 소탕**: 최고 스테이지 −1 까지는 "소탕 ×1/×3/×5" 버튼 — 전투 없이 그 스테이지 보상(강화석·골드·런 XP 없음)을 배율만큼. 비용은 `expeditionDaily` 의 일일 출격 횟수(이미 있음)를 배율만큼. ×10 은 dodge-x3 보유자 전용(유료 가치 유지 — "시간 절약", 밸런스 불변).
  - 코드: `src/game/sweep.ts` 신설(순수 함수: stage → 보상표 × 배율), App 출격 메뉴에 소탕 행. 보상표는 `src/game/stageRewards`(기존 결과 창 계산)를 그대로 호출.
  - 검사: verify-systems "소탕 보상 = 1회 보상 × 배율 · 최고 스테이지는 소탕 불가 · ×10 은 dodgeSpeed3 만".
- **비트 소탕**: 최고 기록 곡은 "기록 반복" 버튼으로 70% 보상(수련은 손맛이 핵심이라 100% 안 줌).

### P1 — 하루 리듬과 2택 (B + C)
- **원정 지도에 "다음 날" 리듬**: 노드 사이에 가벼운 2택 사건 3종을 섞는다(결정적, 노드 번호로 시드): ① 휴식(방어막 +20%) vs 강행(런 XP +1) ② 상인(인장 10 → 선택권 1장) vs 통과 ③ 천사/악마 계약(이번 판 공격 ×1.3 / 피격 ×1.2). 한 판 시작 전 1개, 보스 전 1개 — 손은 두 번, 결정은 둘.
  - 코드: `src/game/dayEvents.ts`(순수) + 출격 안내 모달에 2택 UI. 효과는 `HuntMods`/`RunMods` 와 같은 모디파이어 객체로.
- **스테이지 타입 3종 순환**: 본선 50 스테이지를 10개씩 묶어 **긴(60일형: 웨이브 3 + 레벨업 카드 기본)** · **짧은(30일형: 웨이브 2 + "행운 상인" 머신 1회 — 인장으로 돌려 스킬/스탯)** · **타워형(5일형: 스킬 5개 선택 후 연속 5웨이브)** 을 60→60→30→30→5 순으로. 타워형은 갈림길 정예와 합친다.
  - 코드: `src/game/stages.ts` 에 `stageType(index)`; 웨이브 수·카드 주기·머신 유무를 타입으로. 밸런스 sweep(`scripts/balance-sim.mjs`) 먼저.

### P1 — 특성 이정표 (G)
- **대장간 강화 합계 이정표**: 무기·갑옷·파츠 강화 레벨 합계가 10의 배수마다 "장인 N" 승급, 1/3 지점 골드, 2/3 지점 **영구 특성 1개 선택**(골드 디거 +50% · 융통(카드 1회 재선택) · 건장(출격 횟수 +1) · 지식욕(런 XP +5%) · 황야 서바이벌(방어막 회복 +10%)). 특성은 `CharacterProgress.talents: string[]`.
  - 검사: verify-systems "합계 20 → 2/3 지점에서 선택권 1 · 중복 선택 불가".

### P2 — 빌드 계열 · 상자 루프 · 장비 환급 (H + I + J)
- **진화 경로가 스킬 풀을 가른다**: evolutionPath 별로 레벨업 카드 풀에 계열 카드 3장 추가, 타 계열 카드 −1. 계열 이름은 동료 역할과 같은 단어(근접·원거리·탱커·치유)로 통일(명칭 일관성 — 카피 Go 비판 ✗).
- **상자 포인트**: 뽑기·성벽 10층·주말 균열에서 "비버 상자" → 열면 상자 포인트 → 100점에 상자 1개. 상자 안은 조각·강화석·인장(확률 공시 1장에 합침).
- **강화 되돌림 100% 환급**: 대장간 "되돌리기" — 강화석·골드 전액 환급(수수료 0). 실수 비용을 없애 강화를 자주 누르게.

### 하지 않을 것 (카피 Go 비판에서)
- 허브 빨간 점은 "지금 할 수 있고 보상이 남은 것"에만. 알림 폭탄 금지(최대 3개, 나머지는 카드 안 숫자로).
- 스킬·카드 설명은 숫자로("치명 +15%") — "↑↑" 금지. 같은 효과에 두 이름 금지(`skill-names-in-tests` 검사 유지).
- 합성·승급 재료는 한 자리수. 신화 1개에 에픽 144개 같은 벽 없음.
- 결제는 `PAYMENTS.md` 지급 순서 그대로(2중 결제는 주문 ID 로 막는다).

## 4. 착수 순서
1. P0 허브 카드 6장 + 실패 시 티켓 미소모 (UI 재배치, 하루)
2. P0 성문 소탕 배율 + dodge-x3 ×10 (순수 함수 + 메뉴 행, 반나절)
3. P1 2택 사건 + 스테이지 타입 순환 (밸런스 sweep 포함, 이틀)
4. P1 특성 이정표 (하루)
5. P2 세 가지 (각 반나절~하루)

각 단계는 `verify-all` 과 `scripts/shoot-loop.mjs` 캡처로 닫고, 결과는 이 문서 아래에 "결과" 절로 붙인다.

## 결과 — P0 (2026-10-13 저녁)

- **허브 카드 6장**: 하단 바가 사냥터 · **모험** · 동료 · 상점 4칸이 됐다. "콘텐츠"·"모험" 두 팝업을 지우고 `tab === "hub"` 한 화면(`.hub-page`)에 루틴 줄(균열·일일 퀘스트·강화·파견·시즌, 정산은 전장 핀) + 카드 6장(성문 방어·비트 수련·끝없는 성벽·균열·대장간·파견)을 놓았다. 카드 데이터는 `src/titans/hubCards.ts`(순수): 남은 횟수/티켓/기록 · 오늘 얻는 재화 칩 · 빨간 점은 "지금 할 수 있고 오늘 보상이 남은 것"에만, 최대 3개(알림 폭탄 금지). 카드 그리드에 `nav-popup-grid` 클래스를 같이 둬 기존 캡처·검사 스크립트(`.nav-popup-grid button` "성문 방어")가 그대로 찾는다. 스크립트의 "콘텐츠" 탭 클릭은 전부 "모험"으로 바꿨다.
- **실패 시 티켓 미소모**: 끝없는 성벽 등반권은 시작이 아니라 **첫 층을 깼을 때** 쓴다(`towerTicketPendingRef`). 1층에서 죽으면 그대로. 균열·갈림길은 원래 실패 비용이 없었다.
- **성문 소탕 배율** (`src/game/sweep.ts`): 최고 −1 스테이지 보상을 전투 없이 ×1/×3/×5, 하루 5회 예산(`expeditionDaily.sweeps`). ×10 은 dodge-x3(성문 ×3 배속 영구) 보유자만, 예산 10. 보상은 한 판 기대값(코인 = baseReward×0.72, 견갑 조각 기대값)이고 런 XP·강화 카드·첫 클리어 2배는 없다. 일일 미션 "클리어"엔 배율만큼 더한다. 성문 메뉴 시작 버튼 아래 `.sweep-row`.
- **검사**: verify-systems 에 허브 카드 5단언 · 소탕 4단언. verify-retention 의 "모험 팝업 토글"은 허브 탭 전제로 고쳤다. 헤드리스 캡처로 허브(점 3개·성벽 잠김)와 소탕(5/5 → ×3 → 2/5, 코인 +897) 확인.

## 결과 — P1 (2026-10-13 저녁)

- **2택 사건** (`src/game/dayEvents.ts`): 한 판에 둘 — 출발 전(성문 메뉴 시작 버튼 아래 `.day-event-row`, 첫째가 기본값이라 '시작'만 눌러도 진행) · 대장 등장 순간(HUD `.pact-offer`, 8초, 안 고르면 지나감 — 멈추지 않는다). 긴 공성 = 휴식(방어막 +20%) vs 강행(카드 1장 즉시) · 짧은 돌격 = 통과(코인 +5%) vs 상인(인장 10 → 카드 1장) · 타워형 = 강행 vs 휴식 · 대장 = 천사(피해 ×1.3) vs 악마(피해 ×1.6, 방어막 피해 ×1.25). 효과는 세계 값(runMods.damageMul · barrierTakenMul · coinBonusMul · levelUps)이라 이번 판에만 듣는다. 갈림길·성벽은 사건 없음.
- **스테이지 타입 3종** (`stages.stageType`): 카피 Go 의 60/30/5일 순환을 본선 10칸 안의 슬롯 종류로 대응 — 긴 공성(개막·혼성·포위전·중간 보스·장 대장) · 짧은 돌격(떼·돌진·협공) · 타워형(정예·정예 혼성). 시작 버튼에 타입 라벨, 2택 사건이 타입을 따른다.

- **검사**: verify-systems 에 사건·타입 4단언, 이정표 5단언. 헤드리스로 출발 2택 → 강행 → 시작 직후 카드 확인, 대장 계약 HUD → 천사 → damageMul 1.3 확인.

## 결과 — P2 (2026-10-13 밤)

- **빌드 계열이 카드 풀을 가른다** (`perks.buildWeight`): 진화 경로(novice·swordmaster·guardian·arcane)를 세계에 실어(`world.evolutionPath`) 레벨업 카드 추첨에서 맞는 계열 카드를 2배 무게로 — 검성 = 기본 사격·연사·과부하 같은 화살 카드, 수호자 = 회복·일섬 게이지, 비전 = 스킬 습득·진화·콤보. 다른 계열 카드가 사라지진 않는다(선택의 폭). 초심자는 가중 없음.
- **비버 상자 루프** (`src/economy/chests.ts`): 성벽 10층 · 균열 하루 3회 완료 · 10연 소환에서 상자 1개. 모험 허브 상자 줄(`.hub-chests`)에서 열면 강화석 20(45%) · 인장 8(35%) · 보유 동료 조각 3(20%) — 확률 공시 한 줄 — 와 포인트 10, 100점이면 상자 1 환급. 저장 `chests·chestPoints·chestsOpened`.
- **대장간 되돌리기** (`.forge-revert`): +N → +N−1 로 내리고 그 단계에 낸 골드(`tierAt(N−1).cost`)와 강화석 1을 전액 환급. 실수 비용 0 — 카피 Go 의 "강등 100% 환급". 실패 시도의 골드는 환급하지 않는다(도박 요소는 남긴다).
- **검사**: verify-systems 에 상자 4단언 · 계열 가중 1단언. 헤드리스로 장인 이정표(골드 +6,000 수령 · 융통 선택), 상자 열기, 되돌리기 확인.
