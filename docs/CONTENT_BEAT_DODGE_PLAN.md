# 비트 원정 난이도 레벨 · 화살 원정 검격 재설계 (2026-09-04)

## 1. 비트 원정 — 곡·노트 난이도 레벨

### 문제
- 16곡의 순서가 난이도와 무관했다(첫 곡이 79마디 NORMAL). 카드에는 EASY/NORMAL/HARD 라벨만 있고 "얼마나 어려운지"가 없었다.
- 한 곡은 한 난이도뿐이라 쉬운 곡은 금방 바닥나고 어려운 곡은 진입이 없었다. 판정 창도 난이도와 무관하게 동일했다.
- 클리어 뒤 남는 기록이 "오늘 완료"뿐이라 다시 할 이유가 없었다.

### 설계
| 요소 | 규칙 |
|---|---|
| **레벨 1~10** | 곡마다 `level` 명시. 근거: BPM × 분할(4/8/16) × 패턴 복잡도 × 길이. 사다리(스케줄)는 레벨 오름차순 |
| **곡당 3난이도** | EASY(4분할·링 1·HP 8) / NORMAL(8분할·링 2·HP 7) / HARD(16분할·링 2·HP 6). 재생 BPM은 고정, 노트 밀도·판정만 바뀐다 |
| **판정 창** | PERFECT/GREAT 임계(락 값): EASY .70/.40 · NORMAL .78/.45 · HARD .84/.50 |
| **등급** | 정확도(락 히트/탭) S ≥ 90% · A ≥ 75% · B ≥ 55% · C. 곡×난이도별 최고 등급 저장 |
| **해금** | 다음 곡: 기존 규칙(클리어). HARD: 같은 곡 NORMAL A 이상 |
| **보상** | 난이도 배수 EASY 1.0 / NORMAL 1.35 / HARD 1.8 (기존), 등급 S는 조각 +5 |

레벨 표: black-city-beat 1 · cybernetic-overload 2 · arcade-overdrive 2 · playful-pixels 3 · cherry-pop 3 · happy-strum-day 4 · pixel-rush 4 · one-more-time 5 · azure-sky 5 · turkish-march 6 · starlight-strut 7 · duel 8 · andromeda 8 · plasma-gun 9 · dual-racing 9 · strawberry-lemonade 10.

노트 배치 자체(인트로 강박 → 빌드업 점증 → 드롭 최대 → 브레이크 성김, 레인 프레이즈 순환)는 기존 `buildChart`가 이미 구간별로 밀도를 정하므로 유지한다.

## 2. 화살 원정 — "날아오는 화살을 검객 기술로 벤다"

### 문제 (타당성)
- 검격 키를 누르면 반경 안의 화살이 **자동으로** 잘렸다. 베는 순간·방향이 없어 검객이 아니라 자석이었다.
- 잘린 화살은 두 조각이 되어 플레이어 주위를 **공전하다 되돌아와 공격**했다. 벨수록 적이 늘어나는 셈이라 "왜 베는가"가 성립하지 않았다.

### 설계 (검객 규칙)
| 요소 | 규칙 |
|---|---|
| **스윙** | 검격 = 320ms 스윙. 스윙 중 **앞쪽 220° 호** 안, 반경 내 화살만 벤다. 뒤에서 오는 화살은 못 벤다 → 방향 전환이 플레이가 된다 |
| **정타 = 반사** | 화살 끝이 몸에서 16px 이내일 때 베면 **반사**: 화살이 온 길로 1.4배 속도로 되돌아가고, 화면 밖으로 나가면 궁수 처치(처치 +1 · 보급 +2 · 점수) |
| **베기 = 파쇄** | 그 외 호 안의 화살은 부서져 사라진다(보급 +1 · 점수). 조각·공전 없음 |
| **시간 지연** | 스윙 뒤 남은 지속 시간엔 반경 안 화살이 느려진다(기존 슬로우) — 다음 스윙을 준비하는 창 |
| **쿨다운** | 1,750ms → 1,150ms(강화당 −90, 하한 600). 스윙만으로 베므로 리듬이 빨라야 한다 |
| **참격 게이지(0~100)** | 반사 +22 · 파쇄 +9 · 근접 회피 +4. 가득 차면 **일섬**: 화면의 일반 화살 전부 파쇄 + 1.2초 시간 지연 + 섬광. 게이지 0 |
| **보스 화살** | 기존 규칙(N회 베기) 유지 — 호 안에서만 벤다 |

중독성은 "코앞에서 베면 반사"라는 위험·보상과, 연참(콤보)·게이지 → 일섬의 짧은 축적·해방 주기에서 나온다.

### 검증
- `scripts/verify-content.mjs`: 비트 레벨 사다리·판정 임계·등급·난이도별 노트 수, 화살 스윙 호·반사·파쇄·게이지·일섬을 순수 시뮬로 단언.

## 3. 마저 개발 (2026-09-04, 2차)

### 비트 — 노트 밀도 곡선 고도화
- 구간 밀도표 `SECTION_DENSITY[difficulty]`: EASY 는 드롭이 성기고(기본 강박 유지 75%), HARD 는 브레이크마저 빽빽(45%). 빌드업 램프는 난이도별 시작·끝 확률.
- 클라이맥스: 드롭의 마지막 10%는 확률 없이 기본 강박 전부.
- 프레이즈 필: 4마디 프레이즈의 마지막 마디 끝을 채운다(NORMAL 2스텝 · HARD 4스텝, 스텝 100ms 이상인 곡만). 검증: HARD 드롭 4마디째 9.6 노트 vs 나머지 6.9.
- 드롭 마디당 노트: EASY 1.8 < NORMAL 4.3 < HARD 5.5 (azure-sky).

### 화살 원정 — 검객 규칙에 맞춘 수치 재조정 (봇 시뮬 `scripts/dodge-sim.mjs`)
| 항목 | 전 | 후 | 근거 |
|---|---|---|---|
| 보스 베기 수 | 10 + 4×스테이지 | 4 + 2×스테이지, 정타는 2컷 | 스윙 1회 = 1컷·쿨다운 1.15s 라 예전 수치는 클리어 불가(봇 0/5) |
| 보스 반격 파편 | 플레이어 주위 공전 → 뒤에서 덮침 (2~3발, 유도 포함) | 보스 위치에서 520ms 예고 뒤 정면으로 1발(3티어부터 2발·유도) | "앞쪽만 벤다" 규칙과 충돌, 봇 피격 1위 |
| 유도탄 승격 | 모든 스테이지 13% | 0 / 5 / 6 / 9%, 회전율 1.25~2.35 → 0.9~1.8 | 등 뒤로 감아 도는 궤도가 2위 원인 |
| 3·4스테이지 팬·크로스·버스트 | 팬 410/455, 크로스 505, 버스트 120ms/96ms | 팬 380/420, 크로스 470, 버스트 150/130ms | 초당 8~10발은 스윙으로 대응 불가 |

봇(성장 프로필 Lv 8/21/37/55) 결과: 1스테이지 5/5 클리어·피격 1.2, 2스테이지 5/5·0.4, 3스테이지 4/5·1.4, 4스테이지 3/5·4.4(HP 6). 베기율 33→53%. 1·2스테이지는 `verify-content.mjs`가 게이트(4/5 이상 클리어·피격 ≤ 1.5)로 지킨다.

## 4. 비트 — 홀드·회복·곡 특성·펌프식 레벨 (2026-09-09)

| 항목 | 규칙 |
|---|---|
| **홀드 노트** | 머리를 치고 꼬리까지 **실제로 누르고 있어야** 유효. 꼬리 근처 릴리즈 = 보너스(HOLD), 일찍 떼면 MISS + HP −1, 끝까지 누르면 자동 완주(+회복). 유지 중 같은 레인 추가 입력은 무시. 예전엔 `holdSteps` 만 있고 `hold` 가 비어 롱노트가 단타로 판정됐다 |
| **회복** | 회복 게이지: PERFECT +2 · GREAT +1 · 홀드 완주 +2, 8 마다 HP +1 (상한 maxHp) — 잘 치면 게임 오버가 늦춰진다. 판정 문구 뒤 ♥ |
| **소리 크기(데시벨)** | `SOUND_LOUDNESS`(audio.ts 피크 게인): 킥 .32 · 파이어빗 .2 · 스로트/하이햇 .16 · 트럼펫 .14 · 스네어 .12 · 클릭 .1 · 숨 .07. 레벨 하한(`minLoud`) 아래 소리는 노트가 아니고, 큰 소리일수록 남는다 (레인 풀에서도 제외) |
| **BPM** | 초당 노트 상한 4.2(bpmKeep) 위에 레벨 상한(`notesPerSec`)이 더 걸린다 — 이중 감산 없음 |
| **펌프 레벨 특징** | L1~2 4분음·강박만·롱노트 없음 / L3~4 8분음·롱노트 2스텝 / L5~6 레인 계단(드롭 후반 0→1→2→3)·롱노트 3 / L7~8 16분 드릴(같은 레인 3연타)·롱노트 4 / L9~10 드릴+계단+긴 롱노트, 초당 5.2. 유효 레벨 = 곡 레벨 + 변형(EASY −2 · HARD +2) |

검증: `verify-content.mjs` — 롱노트 머리/꼬리 판정, 레벨 1 채보에 롱노트·작은 소리 없음, 레벨표 단조성, effectiveLevel, HARD 드릴 존재, 회복 게이지.
